# منصة دروس العلوم التفاعلية

تطبيق ويب (PWA) يُثبَّت على التابلت ويعمل بملء الشاشة ودون إنترنت. إعداد أ. علي طاهر البقاشي.

## إضافة درس أو تجربة
1. ارفع ملف الدرس إلى مجلد `lessons/` (وصورة الغلاف إلى `img/` إن وُجدت).
2. أضف سطرًا في `catalog.json` داخل `items`، مثل:
   `{"id":"g7-c2-l1","title":"اسم الدرس","type":"lesson","grade":"7","no":1,"chapter":"الفصل الثاني: ...","desc":"","color":"#2F7BF6","file":"lessons/g7-c2-l1.html","cover":"img/cover-g7-c2-l1.webp"}`
3. أنواع المحتوى (`type`): lesson، lab (المختبر الافتراضي)، activity، contest، assess، video، sheet، extra.
4. الصف (`grade`): 7 أو 8 أو 9. الملفات المقبولة: HTML وPDF وMP4 وصور.

يصل كل محتوى جديد إلى التابلت تلقائيًا عند فتح التطبيق مع اتصال بالإنترنت.
